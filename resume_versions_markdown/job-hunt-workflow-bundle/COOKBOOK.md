# Job Hunt Workflow Cookbook

This file is the quick-start version of the bundled examples. Use it when you want ready-made prompts without opening the reference tree.

## Rebuild The Brief

```text
Review the job-search workspace and reconstruct my latest locked brief before sourcing anything new.
```

## Source New Roles

```text
Find net-new roles that match my brief. Screen for fit, seniority, geography, and recency. Return a prioritized shortlist with rationale.
```

## Create JD Markdown

```text
Create an AI-friendly markdown for this job posting and save it using the repo naming convention.
```

## Tailor For Brand Marketing

```text
Use my global resume and tailor a submit-worthy version for this brand role. Keep HUL grouped and optimize for premium positioning, media, partnerships, and consumer insight.
```

## Tailor For PMM / GTM

```text
Tailor my resume for this PMM role. Optimize for GTM, experimentation, launch execution, analytics, and cross-functional execution.
```

## Tailor For Analytics / Measurement

```text
Tailor my resume for this analytics-led marketing role. Keep it truthful and foreground research, measurement, experimentation, and marketing recommendations.
```

## Final QA

```text
Run a final QA pass on the markdown, HTML, and PDF. Fix any line spillover caused by 1-2 words and verify the export is one page.
```

## Commit Learnings Only After Approval

```text
Capture today’s reusable learnings only after the final version is approved.
```
